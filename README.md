# EFT Landing Page 🌿

A modern and responsive landing page for **EFT**, a mental wellness platform focused on meditation, relaxation, and better sleep.

## Features

- Responsive design for mobile, tablet, and desktop
- Modern UI inspired by wellness and mindfulness apps
- Smooth scrolling header
- FAQ accordion section
- Testimonials and blog sections
- Optimized images with Next.js `Image`
- Built with reusable React components

## Tech Stack

- Next.js
- React
- Tailwind CSS

## Getting Started

```bash
npm install
npm run dev
```
Open `http://localhost:3000` in your browser.

## Preview

A clean and calming user experience designed to promote mental wellness, meditation, and healthy sleep habits.
